🌐 Ücretsiz Seçenekler
1
Railway.app Ücretsiz
En kolay yöntem. GitHub'a yükle → railway.app'te "New Project" → repo seç → otomatik deploy. Aylık $5 ücretsiz kredi var, bot için fazlasıyla yeter.
2
Render.com Ücretsiz
GitHub'a yükle → render.com'da "New Web Service" → repo bağla → deploy. 15 dakika pasif kalırsa uyur, UptimeRobot ile uyandır.
3
Replit Ücretsiz
replit.com'da proje oluştur, dosyaları yükle, Run butonuna bas. UptimeRobot ping ekle, uyumasın.
4
VPS — Contabo / Hetzner €4/ay
En kararlı yöntem. VPS al, Node.js kur, pm2 start index.js ile başlat. Asla kapanmaz.
